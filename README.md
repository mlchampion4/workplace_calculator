# Калькулятор условий труда IT-специалиста (БЖЧ)

Десктопное приложение для оценки условий труда работников IT-сферы по
параметрам безопасности жизнедеятельности человека. Сравнивает измеренные
значения с нормативами СанПиН и ТК РБ, рассчитывает баллы риска, определяет
интегральную категорию условий труда и выдаёт рекомендации.

Разработано в рамках научной работы по дисциплине «Безопасность
жизнедеятельности человека».

---

## Возможности

- Ввод значений по 5 блокам параметров во вкладках Tkinter.
- Автоматическое сравнение с нормативами (оптимум / допустимо / вредно / критично).
- Баллы риска 0–3 по каждому параметру и интегральная категория:
  Оптимальный, Допустимый, Вредный 1 ст., Вредный 2 ст., Опасный.
- Динамические рекомендации по устранению отклонений.
- Работает на стандартной библиотеке Python — без внешних зависимостей.
- Кроссплатформенность: Windows, Linux, macOS.

## Оцениваемые параметры

| Блок | Параметры | Норма (кратко) |
|---|---|---|
| 1. Микроклимат | Температура, влажность, скорость воздуха, Δt поверхностей | 22–24 / 21–23 °C; 40–60 %; ≤ 0,2 м/с; Δt ≤ 2 °C |
| 2. Освещённость | Освещённость, пульсация, яркость, контраст, неравномерность, КЕО | 300–500 лк; ≤ 5 %; 100–200 кд/м²; ≥ 3:1; ≤ 3; ≥ 1,0 % |
| 3. ЭМП от ПЭВМ | ЭСП, ЭП/МП (2 диапазона), ППЭ СВЧ, расстояние | ≤ 500 В; ≤ 25/2,5 В/м; ≤ 250/25 нТл; ≤ 10 мкВт/см²; ≥ 50–70 см |
| 4. Шум | Уровень звука на рабочем месте | ≤ 50 дБА (опт.), ≤ 60 дБА (доп.) |
| 5. Психофизиология | Непрерывная работа, время за экраном, монотонность, переработки | ≤ 45–60 мин; ≤ 6 ч; 1–5; ≤ 120 ч/год; > 10 ч/нед — риск |

---

## Нормативная база

- СанПиН по гигиене труда — микроклимат офисных помещений
- СанПиН 2.2.1/2.1.1.1278 — освещение
- СанПиН 2.2.2/2.4.1340 — ПЭВМ и ЭМП
- СанПиН 2.2.4/2.1.8.562 — шум
- ТК РБ — сверхурочные работы (≤ 120 ч/год)

---

## Методика оценки

1. Балл риска по каждому параметру:
   - 0 — оптимум
   - 1 — допустимо
   - 2 — вредно
   - 3 — критично

2. Интегральная категория:

| Условие | Категория |
|---|---|
| Есть балл 3 | Опасный |
| ≥ 5 параметров с баллом 2 | Вредный 2 ст. |
| 1–4 параметра с баллом 2 | Вредный 1 ст. |
| ≥ 3 параметра с баллом 1 | Допустимый |
| Иначе | Оптимальный |

3. Рекомендации формируются по параметрам с баллом ≥ 1.

## Установка и запуск

### Требования

- Python 3.9+
- Tkinter (в стандартной поставке; на Linux — пакет python3-tk)

### Запуск

Клонировать репозиторий:

    git clone https://github.com/mlchampion4/workplace_calculator.git
    cd workplace-calculator

Создать виртуальное окружение и активировать:

    python -m venv .venv
    source .venv/bin/activate      (Linux/macOS)
    .venv\Scripts\activate         (Windows)

Запустить приложение:

    python -m app.main.py

Linux: если Tkinter отсутствует — sudo apt install python3-tk.

## Использование

1. Запустите приложение.
2. Заполните вкладки:
   - 1. Микроклимат — период года, температура, влажность, скорость воздуха.
   - 2. Освещённость — люксы, пульсация, яркость, контраст, неравномерность, КЕО.
   - 3. ЭМП от ПЭВМ — параметры поля и расстояние до экрана.
   - 4. Шум — уровень звука.
   - 5. Психофизиология — режим труда и переработки.
3. Нажмите кнопку «Рассчитать».
4. Результаты:
   - верхняя панель — итоговая категория и счётчик баллов;
   - таблица — построчная оценка с рекомендацией.
